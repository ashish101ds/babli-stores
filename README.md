Product photos for Babli Stores & Cosmetics

Place final product photos in the `assets/` folder with these filenames (or update the HTML to match your filenames):

- hero.jpg        — recommended ~2000×1200 (hero background)
- saree1.jpg      — recommended ~1000×700 (card)
- saree_festive.jpg — recommended ~1000×700 (card)
- beauty.jpg      — recommended ~1000×700 (card)
- about.jpg       — recommended ~1200×800 (about section)

Notes:
- Keep filenames lowercase and avoid spaces.
- Optimize images for web (JPEG/WEBP, quality ~75) to balance quality and load time.
- To preview locally, open `babli_stores.html` in a browser.
